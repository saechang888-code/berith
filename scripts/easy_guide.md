# 「오늘의 말로 풀어 읽기」 옮기는 기준 (주인님 결정 2026-11-01)

개역한글판(1961) 본문을 2026년 한국 사람이 읽자마자 와닿는 우리말로 풀어 옮긴다.
앱에서 개역한글 원문 옆에 붙여 보여 주는 **참고용 풀이**이며, 새 성경 번역본이 아니다.

## 문체
- 해요체("~해요, ~했어요, ~이에요"). 서술도 "그가 말했어요", "예수님이 대답하셨어요".
- 예수님의 말씀도 해요체로 따뜻하게("내가 분명히 말해요", "나를 따라와요"). 사람들이 예수님께 하는 말도 해요체("선생님, ~이지요?").
- 짧고 자연스러운 문장. 한자어·옛말은 쉬운 말로(가라사대→말씀하셨어요, 이르노니→말해요, ~하였더라→~했어요).

## 뜻과 교리
- 한 절은 한 절로. 절을 합치거나 나누지 않는다. 절 번호를 그대로 지킨다.
- 원문의 뜻을 더하거나 빼지 않는다. 설명을 덧붙이지 말고, 꼭 필요하면 아주 짧게 괄호로만.
- 교리의 핵심 말은 살린다: 하나님, 예수님, 성령, 말씀, 은혜, 믿음, 죄, 십자가, 영광, 하나님 나라, 어린 양.
- 오해를 사거나 낡은 말은 교리에 어긋나지 않는 오늘의 말로:
  - 진실로 진실로 → "내가 분명히 말해요" / 영생 → "영원한 생명" / 거듭나다 → "새로 태어나다"
  - 독생자 → "하나뿐인 아들" / 보혜사 → 처음엔 "보혜사(곁에서 도우시는 분)", 그 뒤엔 "도우시는 분"
  - 표적 → "표적" 그대로 두되 문맥상 필요하면 "놀라운 표적" / 바리새인 → "바리새파 사람"
  - 심판 → "심판" (벌 받다로 바꾸지 않음) / 구원 → "구원"
- 사람·땅 이름은 오늘 교회에서 흔히 쓰는 표기(세례 요한, 베드로, 갈릴리, 예루살렘 등).
- 존칭: 하나님·예수님·성령께 "~께서/~님이 ~하셨어요".

## 내는 모양
JSON: `{"chapter번호": ["1절 풀이", "2절 풀이", ...], ...}` — 원문 절 수와 똑같이. 원문에 "(○절에 포함되어 있음)" 같은 빈 절이 있으면 그대로 두지 말고 ""(빈 문자열).

## 주인님 추가 결정 (2026-11-01)
- 태초 → "처음 창조하실 때" / "세상이 처음 창조될 때" (예: 1:1 "세상이 처음 창조될 때 말씀이 계셨어요", 1:2 "그분은 처음 창조하실 때 하나님과 함께 계셨어요")
- 육 → "몸" (예: 3:6 "몸에서 태어난 것은 몸이고, 성령에게서 태어난 것은 영이에요", 1:14 "말씀이 사람의 몸이 되어", 6:63 "몸은 아무 도움이 되지 않아요"). 육신·육체도 문맥에 맞게 "몸"으로.
- 11:43 예수님의 부르심은 위엄 있게: "나사로여! 나오시오!" (주인님 결정)
- 6:51~58의 "살"(내 살을 먹고)은 성찬과 이어지는 말이라 "살" 그대로 둠

## 주인님 결정 2 (2026-11-01 저녁) — 더 현대어로, "돕는 글"로
- 이것은 성경 번역본이 아니라, **오늘 사람이 읽고 바로 이해하도록 돕는 풀이 글**이다. 직역에 매이지 말고 2026년 한국 사람이 실제로 쓰는 말로 시원하게 풀어 쓴다.
- 허용: 어순·문장 나누기 자유, 옛 문화·단위·관습을 오늘 말로 바꾸기, 뜻을 분명하게 하는 짧은 말을 문장 안에 자연스럽게 녹이기(괄호 남발 금지).
- 금지: 원문에 없는 사건·생각·감정을 지어내기, 해석·적용 설교 붙이기, 교리를 흐리거나 바꾸기.
- 여전히: 절 수 그대로, 해요체, 교리 핵심어(하나님·성령·은혜·믿음·죄·십자가·구원·심판·영광·하나님 나라·어린 양) 유지, 앞의 결정(태초→처음 창조, 육→몸, 11:43 "나사로여! 나오시오!", 6장 "내 살") 유지.
- 말맛 예시(요 3장):
  - 1 바리새파 사람 가운데 니고데모라는 사람이 있었어요. 유대 사람들 사이에서 손꼽히는 지도자였어요.
  - 2 그가 밤에 예수님을 찾아와 말했어요. "선생님, 저희는 선생님이 하나님께서 보내신 분이라는 걸 알아요. 하나님이 함께하지 않으시면, 선생님이 보여 주시는 그런 놀라운 표적은 아무도 못 하니까요."
  - 3 예수님이 대답하셨어요. "정말 중요한 걸 말해 줄게요. 사람이 완전히 새로 태어나지 않으면 하나님 나라를 볼 수 없어요."
  - 8 바람은 제 마음대로 불지요. 소리는 들려도 어디서 와서 어디로 가는지는 아무도 몰라요. 성령으로 새로 태어난 사람도 다 그래요.

## 요한복음에서 정한 것 (다른 책에도 그대로)
- "진실로 진실로 이르노니" → "정말 중요한 걸 말해 줄게요" / "너희" → "여러분" / 반말 부름말("시몬아") → "시몬" / "여자여" → "부인"

## 욥기를 풀 때 (2026-11-01)
- 욥기는 대부분 시로 된 대화다. 시의 비유는 살리되, 오늘 사람이 바로 그림이 그려지는 말로 푼다. 한 절이 무슨 뜻인지 읽자마자 알 수 있어야 한다.
- 말하는 사람의 말투를 살린다: 욥(괴롭고 억울한 사람의 솔직한 말), 세 친구(가르치려 드는 말), 엘리후(젊고 열띤 말), 하나님(위엄 있지만 해요체 — "너는 ~ 알고 있느냐" → "너는 ~ 알고 있나요?" 대신 위엄을 살려 "네가 ~ 아느냐?"처럼 하지 말고, "~를 아는가?" 같은 하오체도 피하고 해요체로 무게 있게: "땅의 기초를 놓을 때 너는 어디 있었나요? 알면 말해 보세요.").
- 생소한 동물·별자리·광물 이름은 오늘 말로(예: 하마·악어 등 학계에서 흔히 보는 뜻), 꼭 필요하면 짧게.
- 하나님을 원망하는 욥의 말은 원문 그대로의 세기로 옮긴다(누그러뜨리지 않음).
